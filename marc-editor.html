📕 마크 검사기

일루스 MARC 붙여넣기 → 틀린 곳 빨간 표시 → 고쳐서 다시 일루스에 붙여넣기 (KDC는 검사 제외)

✏️ 원문 입력·수정 일루스에서 복사한 마크를 붙여넣고 여기서 직접 고치세요

🔍 검사 결과 빨간색 = 오류, 주황색 = 확인 필요 · 클릭하면 이유가 보여요

📝 고칠 곳

· 식별기호는 ▼ / $ / ǂ 모두 인식하고, 지시기호 공백은 빈칸·_·# 모두 인식합니다. 고친 결과는 붙여넣은 원래 형식을 그대로 유지합니다.
· 저자기호는 리재철 한글순도표 제5표(성 첫 글자 + 둘째 글자 자음·모음 번호 + 서명 첫 글자 초성) 기준입니다. 도서관에서 다른 표를 쓰면 저자기호 항목은 참고만 하세요.
· 입력한 내용은 이 브라우저 안에서만 처리되고 어디에도 전송되지 않습니다.
